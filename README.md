# Un Amor con Propósito: Libro Digital Interactivo

Este repositorio contiene un libro digital interactivo que permite navegar a través de capítulos como si fueran páginas de un libro físico.

## 📖 Contenido

- **libro/**: Aplicación web del libro digital
  - `index.html`: Página principal
  - `assets/style.css`: Estilos visuales tipo libro
  - `assets/script.js`: Lógica de navegación
  - `README.md`: Documentación del proyecto

## 🚀 Uso

1. Abre `libro/index.html` en tu navegador
2. Navega por los capítulos desde el índice
3. Usa los botones de navegación para moverte entre páginas
