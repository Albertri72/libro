# libro

Este repositorio contiene un libro digital interactivo sobre una historia de noviazgo.

## 🚩 NUEVO: CTF Challenge (Capture The Flag)

¡Este proyecto ahora incluye un desafío de ciberseguridad! Hay **10 banderas (flags)** escondidas en el código que debes encontrar usando tus habilidades de hacking ético.

### Cómo participar:
1. Abre `libro/index.html` en tu navegador
2. Usa las herramientas de desarrollo (DevTools - F12)
3. Busca las 10 flags escondidas en HTML, CSS y JavaScript
4. Valida tus flags en `ctf-validator.html`
5. Lee `CTF_README.md` para instrucciones completas y pistas

**Niveles de dificultad**: Principiante, Intermedio, Avanzado y Maestro

¡Buena suerte, hacker! 🎯
